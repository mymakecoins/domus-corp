# Débitos externos — V1-201

Antes da distribuição devem ser definidos:

- assinatura de código, notarização e certificados por sistema operacional;
- formatos e canais de instalador, update server e política de rollback;
- URL HTTPS e pins/CA/proxy do Control Plane por ambiente;
- matriz Windows/macOS/Linux, smoke tests e requisitos corporativos;
- telemetria de crash, consentimento e retenção.

O pacote Linux local não assinado é exclusivamente uma prova de desenvolvimento.
