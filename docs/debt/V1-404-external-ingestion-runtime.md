# Débitos externos — V1-404

Antes de promover o pipeline para qualquer ambiente que não seja desenvolvimento, devem ser
decididos e homologados: broker/fila e DLQ físicos, concorrência e autoscaling, sandbox do SO,
limites e timeouts por formato, versões/CVEs dos parsers, observabilidade/SLOs, storage de
temporários, capacidade, retenção, alertas e runbooks. Os valores da V1-404 são apenas defaults
seguros para fixtures sintéticas de desenvolvimento e não autorizam processamento corporativo.
