# Débitos externos — V1-301

Ficam para decisão antes de promoção, sem bloquear desenvolvimento:

- providers, endpoints, modelos e credenciais reais por ambiente;
- allowlist de rede, DNS, proxy, certificados, mTLS e regras de firewall;
- timeouts e parâmetros operacionais específicos de cada provider;
- requisitos contratuais de retenção, região, privacidade e DPA;
- estratégia de rollout e canários externos.

Nenhum desses valores é presumido como default de produção.
