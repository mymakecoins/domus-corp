# Débitos externos — V1-202

Antes de promoção devem ser definidos:

- cópia final, localização e aprovação formal de consentimento;
- retenção e exclusão por jurisdição;
- backup, roaming profile, MDM e migração entre dispositivos;
- telemetria/crash reporting com consentimento e redaction;
- comportamento por SO quando o backend seguro estiver indisponível.

O sistema continua bloqueando persistência sensível quando não há criptografia real.
